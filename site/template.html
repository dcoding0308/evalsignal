EvalSignal

Is an AI change a real improvement, or just noise?

You changed a prompt or a model, reran your test cases, and the score moved. EvalSignal compares the two runs case by case and tells you whether the change is real, how sure you can be, and how many test cases you would need if you cannot tell yet.

1 · Compare two versions

A score moved. Is it real?

Each example has a "before" and an "after" run of the same test cases. The bar shows the measured change (dot) and the range the true change most likely lies in (line). If the range crosses zero, the data cannot rule out "no change".

2 · Find hidden regressions

The average is flat. One topic broke.

An overall score can stay the same while one category collapses. EvalSignal checks every category, and adjusts for checking several at once (Holm correction), so a category is only flagged when the drop is unlikely to be chance.

3 · Explain uncertainty

"No meaningful change" is not "not enough evidence"

Both mean "do not panic", but they mean different things. One is evidence that nothing important changed; the other says the test set is too small to know.
